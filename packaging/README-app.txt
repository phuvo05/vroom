VROOM - Driving Challenge (Windows)
===================================

1. Giải nén cả thư mục VROOM (không chỉ riêng file VROOM.exe).
2. Đặt file model best.pth vào cùng thư mục với VROOM.exe
   (hoặc vào thư mục con checkpoints\best.pth).
3. Mở VROOM.exe. AI sẽ tự lái map đầu tiên.

Không có best.pth: bấm "Chọn model .pth" để chọn file, hoặc chuyển ĐIỀU KHIỂN sang "Tự lái".
Tự lái: click vào khung hình, dùng phím mũi tên / WASD, Space để phanh.

Không cần cài Python hay GPU; ứng dụng chạy trên CPU.
Lần mở đầu tiên có thể mất 10-20 giây. Windows SmartScreen có thể cảnh báo vì ứng dụng
chưa được ký số: bấm "More info" -> "Run anyway".
